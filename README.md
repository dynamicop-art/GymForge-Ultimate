# GymForge Ultimate V3 — Web Companion

This folder is the web UI loaded by the GymForge Android app. Upload the **contents of this folder** to the root of the existing `GymForge-Ultimate` GitHub repository.

## V3 additions
- Native Android bridge support
- Native notification permission status
- Test notification button
- Smart Coach state sync to Android
- Android closed-app reminders handled by the companion Android app
- AI Food Scanner remains connected to your Cloudflare Worker

The Android app loads: `https://dynamicop-art.github.io/GymForge-Ultimate/`
